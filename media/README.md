# Your photos & videos

Anything you upload to this folder shows up in the website's gallery automatically.

## How to upload (phone or computer)
1. Open https://github.com/Vasquez-Tacos/vasquez-tacos.github.io/tree/main/media
2. Tap **Add file → Upload files**.
3. Pick your photos or videos, then tap **Commit changes**.

That's it. The newest uploads show first.

## Tips
- Photos: .jpg, .png or .webp. Videos: .mp4 works everywhere (.mov works too).
- Keep videos short (under 60 seconds). GitHub's limit is 25 MB per file when uploading from the website.
- Name a file like `wedding-taco-bar.jpg` and the gallery uses "Wedding taco bar" as its caption. Phone names like `IMG_1234.jpg` show without a caption.
- To remove something, open the file here and delete it.
